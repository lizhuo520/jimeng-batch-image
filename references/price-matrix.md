# 即梦 AI 价格矩阵与模型选型指南

本文档记录即梦 AI（jimeng.jianying.com）生图模型的实测价格矩阵、分辨率消耗梯度与选型策略。

---

| 模型 | 支持分辨率 | 积分消耗（每张） | VIP 限制 | 推荐场景 |
|---|---|---|---|---|
| **Seedream 4.7** *(默认)* | 2K / 4K | **1** / 2 | 否 | **性价比之王（默认首选）**，综合画质高、成本最低 |
| **Seedream 4.6** | 2K / 4K | **1** / 2 | 否 | 次选经济档，稳定性好 |
| **Seedream 4.1** | 2K / 4K | **1** / 2 | 否 | 经典经济档 |
| **Seedream 4.0** | 2K | **1** | 否 | 最低基础档 |
| **Seedream 5.0 Flash** | 1.5K / 2K | 3 / 3 | 否 | 追求极速生成与新模型表现时使用 |
| **Seedream 5.0 Lite** | 2K / 4K | 3 / 4 | 否 | 轻量化中档画质 |
| **Seedream 4.5** | 2K / 4K | 3 / 4 | 否 | 过渡版本 |

> - `Seedream 3.1` 与 `3.0` 在前端工具栏不显示单价（程序内部记录为 `None`），且无法调整张数。千万不要因为前端不显示就误以为是免费档。
> - `Seedream 5.0 Pro` 的 1.5K 档偶尔会有「限免 1 张」活动（工具栏显示 0/张，原价 5/张），常规价格为 2.5/张。

## 2. 选型与降级策略

程序内置了 `ensure_free_setting()` 自动策略控制器，优先级顺序为：
1. **模型优先序**：`Seedream 4.7` → `4.6` → `4.1` → `4.0` → `5.0 Lite` → `5.0 Flash` → `4.5` → `3.1` → `3.0` → `5.0 Pro` → `图片美学模型 V8.2`。
2. **张数控制**：默认强制压缩为 **1 张**（切模型时平台前端会自动回弹到 4 张或 2 张，程序会自动压回 1 张）。
3. **分辨率选择**：优先选择 **2K**（在 4.x 系列中 2K 仅耗 1 积分，4K 耗 2 积分）。
4. **画幅比例**：默认 `智能比例`（用户指定）。⚠️ 实测该档**由服务端自算构图、尺寸不稳定**（2048×2048 与 2304×1728 都出现过），要确定画幅必须显式传 `--ratio`，详见 [ratio-and-size.md](ratio-and-size.md)。

---

## 3. 页面单价动态提取机制

由于即梦前端改版频繁，单价获取采用两级保障：
1. **DOM 实时解析**：在底部工具栏扫描 `span[class*="actual-credits"]`，提取实际价格 `X/张`。
2. **静态价格矩阵兜底**：若页面未抓取到实际单价节点，程序会自动使用上述 `PRICE_MATRIX` 根据当前识别的模型与分辨率进行静态兜底，防止出现“单价未知”导致额度计算中断。
